        Comment obtenir un jeton GitHub ?
        1. Ouvre github.com › Settings › Fine-grained tokens.
        2. Nom : alterplan, expiration au choix (1 an par exemple).
        3. Repository access : Only select repositories › .
        4. Permissions › Repository › Contents : Read and write.
        5. Génère, copie le jeton et colle-le ci-dessous. Il reste sur cet appareil.

        L'autre parent peut faire de même avec son propre compte GitHub, s'il a accès au repo, ou utiliser un jeton que tu lui transmets.
